# 定量倒液 / Portion Fluids

Minecraft 1.20.1 Forge mod for TerraFirmaCraft 3.2 or newer. Forge 47 or newer. Firmalife is optional.

工作台里用流体容器的配方只扣固定的一份液体，并把容器还回来。允许陶壶的配方扣 100 mB，必须用木桶或铁桶的配方扣 1000 mB。容器本身会变成成品的配方不改。大桶、锅、搅拌碗不改。

## Build / 构建

JDK 17 and Gradle 8.10. Put `TerraFirmaCraft-Forge-1.20.1-3.2.12.jar` in `libs/`. Do not commit that jar.

需要 JDK 17 和 Gradle 8.10。把 `TerraFirmaCraft-Forge-1.20.1-3.2.12.jar` 放到 `libs/`。不要把这个 jar 提交进仓库。

```
gradle build
```

The release jar in this folder is `portion_fluids-1.0.0.jar`.

成品是本目录里的 `portion_fluids-1.0.0.jar`。
